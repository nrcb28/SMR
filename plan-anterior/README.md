# Plan anterior de SMR: archivo didáctico

Esta carpeta conserva guías de **Formación y orientación laboral, Empresa e iniciativa emprendedora y Formación en centros de trabajo** para facilitar el estudio de materiales y programaciones del plan anterior. No presenta esas asignaturas como módulos autónomos del plan actual de Madrid.

La modificación curricular madrileña de 2024 suprimió estos módulos e incorporó la nueva estructura. La situación de estudiantes procedentes del plan anterior depende de las disposiciones transitorias y de su expediente; no se deduce de este repositorio una convalidación, exención o matrícula. Consulta el [mapa curricular y sus fuentes](../docs/curriculo-madrid.md).

La relación entre contenidos es orientativa; no establece equivalencias administrativas.

Los casos usan datos ficticios. Cuando se estudia una relación laboral o un trámite actual, se consultan las fuentes vigentes, aunque la asignatura que sirve de referencia sea histórica. Una guía antigua no mantiene vigentes tipos de contrato, importes o procedimientos derogados.
