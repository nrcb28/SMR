# FCT histórica: simulaciones y seguimiento

## Simulación 1. Preparar una reinstalación

Un usuario ficticio indica que el equipo «va lento» y solicita formatear. El alumno debe abrir una ficha antes de actuar: síntomas, alcance, pruebas, persona que autoriza, datos a preservar, copia verificada, licencias y aceptación. La respuesta correcta no comienza con el instalador.

**Solución:** comprobar si la reinstalación es necesaria y está autorizada. La copia debe poder recuperarse, no solo existir. El escenario se resuelve en una VM con datos sintéticos; una intervención real la dirige el responsable de la empresa.

## Simulación 2. Alta de usuario

Se recibe un correo informal pidiendo «los mismos permisos que dirección». Registra la petición y solicita validación según el procedimiento. No clones privilegios de una cuenta sensible. Un plan correcto identifica rol, grupos aprobados, caducidad si procede y prueba de acceso; evita registrar contraseñas en la memoria.

**Aceptación:** demuestra mínimo privilegio y distingue solicitud de autorización. Si no hay información suficiente, el resultado válido es un escalado documentado.

## Revisión de una memoria

Una memoria sólida permite entender la competencia sin revelar información de la empresa. Revisa si cada afirmación tiene evidencia permitida o validación, si distingue observación y ejecución, y si reconoce límites. Las capturas se revisan también por metadatos y contenido de fondo: una ventana secundaria puede mostrar datos aunque el objeto principal esté anonimizado.

**Pregunta:** ¿puedo subir a GitHub un diagrama interno si cambio el nombre de la empresa? **Respuesta:** no se presupone autorización. El diagrama puede seguir revelando infraestructura y ser material ajeno. Crea un ejemplo sintético y obtén las validaciones requeridas para cualquier material real.

**Pregunta:** ¿es mejor ocultar un error pequeño y repetir la tarea? **Respuesta:** no. Un cambio puede haber afectado al servicio o a las evidencias. Se comunica de inmediato y se sigue el procedimiento de recuperación.
