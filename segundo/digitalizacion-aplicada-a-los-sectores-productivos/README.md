# Digitalización aplicada a los sectores productivos · 1664

Módulo transversal de segundo de SMR en Madrid. Esta carpeta estudia cómo transformar un proceso de una organización mediante sistemas, datos y servicios, con criterios de coste, seguridad y utilidad. Digitalizar una hoja de papel no garantiza mejorar el proceso: hay que definir quién introduce la información, quién puede modificarla y cómo se comprueba el resultado.

## Materiales

1. [Guía técnica: procesos, IT/OT, nube, datos, IoT e IA](01-guia.md).
2. [Prácticas, caso de empresa y evaluación](02-practicas-y-evaluacion.md).
3. [Datos, integraciones y gobierno: CSV, JSON, API y responsabilidades](03-datos-integraciones-y-gobierno.md).
4. [Casos completos de transformación, TCO y evaluación de IA](04-casos-de-transformacion-y-costes.md).

**Prerrequisitos:** fundamentos de redes, sistemas operativos y hojas de cálculo. **Resultado esperado:** proponer una mejora medible para una pequeña organización, explicar su arquitectura, identificar riesgos y verificar si realmente reduce errores o tiempo.

La ruta recomendada es modelar un proceso actual, definir sus datos y permisos, comparar soluciones, realizar una prueba con datos sintéticos y evaluar el resultado frente a una línea base. Mantén un registro de supuestos; un ahorro estimado no es un ahorro ya demostrado.

La ampliación desarrolla conciliación de importaciones, contratos de datos, reintentos, idempotencia y actualizaciones concurrentes. Los casos resueltos permiten revisar un piloto, comparar costes con un horizonte homogéneo y calcular precisión, cobertura y F1 de un clasificador. Se estudia tanto el procedimiento como los límites que impiden presentar una mejora hipotética como resultado demostrado.
