## Resultados prácticos esperados

Al terminar deberías tener una matriz de ofertas y evidencias, un CV adaptado sin afirmaciones falsas, una entrevista técnica preparada y una propuesta de servicio con alcance, costes, precio, capacidad y flujo de caja. El proyecto puede ser una iniciativa dentro de una empresa: el emprendimiento no exige crear una sociedad ni asumir riesgo económico real para aprender.

Las cifras son ficticias y sirven para comprender relaciones matemáticas. Las rúbricas y las duraciones de actividad pertenecen a este material y no son criterios oficiales. Los requisitos académicos aplicables se consultan en el [mapa curricular](../../docs/curriculo-madrid.md).

## Ruta de trabajo

Primero identifica un puesto concreto y selecciona pruebas de tus competencias. Después practica comunicación y trabajo en equipo. Por último diseña un servicio pequeño, valida sus supuestos y analiza si los números y la capacidad de ejecución son compatibles. No completes trámites mercantiles, presentes impuestos ni contrates productos de pago para realizar los ejercicios.
